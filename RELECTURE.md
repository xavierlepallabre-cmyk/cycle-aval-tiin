# Relire Cycle aval TIIN — mode d'emploi

Merci d'avoir accepté de relire cette application. Elle sert à des apprentis de Bac Pro TIIN (niveau baccalauréat professionnel) : le but est d'être **juste**, sans entrer dans le détail d'une documentation d'exploitation.

**Adresse :** https://xavierlepallabre-cmyk.github.io/cycle-aval-tiin/ (ordinateur, tablette ou téléphone).

## Ce qui est attendu

- les **erreurs** : un fait, un chiffre, un ordre d'opérations, un nom d'atelier faux ;
- les **imprécisions** : une simplification qui deviendrait fausse, un chiffre périmé ;
- les **schémas** : un flux mal orienté, un équipement mal placé, une étiquette trompeuse ;
- les **sources** : une donnée qui mérite une meilleure source (la liste actuelle est dans `SOURCES.md`) ;
- toute **suggestion** utile à des apprentis.

## Comment faire

1. Ouvrez un parcours (La Hague ou Andra). Le synoptique donne la vue d'ensemble ; les chapitres en haut mènent aux vues détaillées, numérotées 1.1, 1.2, 2.1… Chaque vue se lit étape par étape (boutons « Étape suivante » ou numéros).
2. Quand quelque chose ne va pas, touchez **Relecture** (en haut à droite, ou Alt+R). L'endroit est noté tout seul, par exemple « La Hague › 2.1 R1 · T1 › étape 2/7 : Cisaillage ».
3. Choisissez le type (Erreur, Imprécision, Formulation, Schéma, Source, Suggestion), écrivez la remarque et, si possible, la bonne version et sa source. Touchez **Ajouter la remarque**.
4. Les remarques restent enregistrées sur l'appareil, même si vous fermez la page. Vous pouvez relire en plusieurs fois.
5. À la fin, touchez **Télécharger le fichier** (ou **Copier le texte**) et renvoyez-le à l'auteur par courriel.

Les remarques ne sont envoyées nulle part automatiquement : elles ne quittent l'appareil que par le fichier que vous transmettez.
